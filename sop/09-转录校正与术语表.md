## 这一篇管什么

转写稿从原始输出到可以动笔整理之间的那一道校正。适用两种来源：

- **B 站 AI 字幕**（多数期）。专有名词准确率不低，错的集中在同音字和讳称
- **本地 whisper 转录**（B 站没生成字幕轨的那些期）。错得更多，人名地名是重灾区

两种来源套同一张表。表在 `scripts/transcript-terms.json`，脚本是
`scripts/apply-transcript-terms.py`。做法照搬马司库项目的两层结构
（`马司库/sop/02-校正与审查.md`），多加了一层讳称对照。

## 三层结构

### 一、`terms` 术语表

跟出现在哪一期无关的确定性错误。左边错，右边对，按长度倒序替换，长词先命中。

```json
"狼狼": "朗朗",
"郎朗": ["朗朗", "弹", "钢琴", "演奏"],
"信都": ["信托", "念", "读", "看", "写"]
```

数组形式第一项是正确词，后面是禁止后缀：后面跟着这些字时不替换。给可能撞上
常用词的短词用。「信都」必须带禁止后缀，因为「这两封信都念完了」是正常句子；
「郎朗」带上钢琴相关的后缀，是防以后真的聊到那位钢琴家。

### 二、`manual` 精修层

按期号生效，跑在术语表之后。用于两种情况：

- 同一个错词在不同期对应不同正确词。LIVE031 里「飞机一共才有多少人」说的是
  西班牙在非洲的飞地，别的期里「飞机」就是飞机，不能统一改
- 整句被转坏，只在这一处成立的重写。「上护手」是「上户口」，「给那些人麻痹」
  是「给那些人马币」，这类词单独拎出来全局替换会误伤

**左边要写术语表处理之后的文本。** 精修跑在术语表后面，如果那句话里的词已经被
术语表改过，精修就匹配不上。跑完看输出里有没有「以下精修没匹配上」，有就是左边写错了。

### 三、`aliases` 讳称对照

这一层颖响力特有，马司库没有。主播用一整套讳称讲敏感对象：东大是中国，大毛是
俄罗斯，小乌是乌克兰，朗朗是伊朗，美丽国是美国，S3 是第三次世界大战。车圈和
科技公司另有一套《笑傲江湖》化名，对应关系写在 `content/keywords/` 的词条里。

**这一层只用来读懂转写稿，任何情况下都不替换。** 网页正文一律保留讳称，
对应关系放进 `boundaries` 声明为通行读法，不作事实认定。整理时把讳称解码成
真实对象写进正文，等于替主播下判断，这是踩过的线。

## 命令

```bash
python3 scripts/apply-transcript-terms.py --dry       # 只报告，不落盘
python3 scripts/apply-transcript-terms.py LIVE030     # 指定几期
python3 scripts/apply-transcript-terms.py             # 全部，写 .transcript.fixed.txt
```

原始 `LIVExxx.transcript.txt` 永远不改，校正结果写成 `LIxxx.transcript.fixed.txt`。
**动笔整理时读 fixed 那一份。**

## 加新条目之前必须扫全库

不许凭一处出现就下全局替换。这条是马司库那边用真实事故换来的。

```bash
cd workbench && python3 -c "
import glob
for f in sorted(glob.glob('LIVE*/*.transcript.txt')):
    for line in open(f).read().split('\n'):
        if '小屋' in line: print(f.split('/')[0], line.strip()[:45])
"
```

看它出现的每一处上下文。「小屋」扫完 30 期确认全是乌克兰的语境，没有一处指房子，
才敢全局替换，并且仍然带上「里/子/顶/住」这几个禁止后缀防以后撞上。

## 错误的四个类型

按已扫过的 30 期归纳，从易到难：

**讳称写歪**　最多，也最容易被忽略，因为写歪之后仍然读得通。朗朗写成郎朗（57 处）
或者狼狼（4 处），小乌写成小屋（33 处）或者小吴（17 处）。这类不改的后果是搜索和
关键词全部对不上。

**同音字**　核的问题转成「和的问题」，堰塞湖转成「艳色湖」，理财转成「李财」。

**专有名词**　保诚转成「宝城」，娃哈哈转成「哇哈哈」，CRS 转成「CIS」。
B 站 AI 字幕在这一类上比 whisper 稳，霍尔木兹、马六甲、李光耀、英伟达这些
30 期一次都没错过。

**整串错**　不是错字，是整句读不懂。「一个军旅一麦迪」是金缕玉衣，
「只要邮过来都给你们上护手」是「只要游过来都给你们上户口」。这类只能通读发现，
必须走精修层。

## 已知的坑

- **whisper 出来的稿子先量时长再读。** 2026-08-09 下 LIVE030 的音频，yt-dlp 报成功、
  退出码 0，转出来的 mp3 只有 7.7 分钟，视频是 106 分钟。拿 `ffprobe` 的 duration
  比对视频时长才发现。转录产出同理，看最后一条字幕的时间戳覆盖到多少秒
- **不带 wbi 签名的 `player/v2` 接口会返回别人的字幕。** 同一条视频连查几次，每次
  返回不同 id 的轨，拉下来是旅游和短剧的内容，合并起来比视频本身还长 3700 秒。
  查一条视频到底有没有字幕，用 `x/player/wbi/v2` 加签名，或者直接看 yt-dlp 的
  `--list-subs`
- **术语表改完要抽查 fixed。** 加规则就跑、从不回看，是马司库那边被抓到过的做法
