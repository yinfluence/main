# EP140 Knowledge Map Interview Context

Task statement: Rework EP140 knowledge map so it behaves like an expandable thought map rather than an information archive.

Desired outcome: The first view should show a simple five-stage path. Opening a stage should reveal how that stage's thought moves from one point to the next. Each thought node can then connect to deeper side knowledge, unspoken implications, extensions, and comparisons.

Stated solution: User prefers five stage points as the first layer. Clicking the first point should show the first stage's thought path and the internal logic steps. Each associated thought node can be opened again to reveal side knowledge.

Probable intent hypothesis: The user wants the page to make the author's thinking process legible first, then let readers explore the richer knowledge world generated by each idea. The current card-grid layout feels like scattered notes and does not create focus.

Known facts/evidence:
- Screenshot shows expanded stage with many equal-weight cards.
- User says the knowledge volume is still small but the layout already feels chaotic.
- User rejects the previous "脉络 / 分支 / 网络" split except that "脉络" is closest.
- User wants node-to-node expansion: a point opens to thought logic, and each logic node opens to side knowledge.

Constraints:
- Local-only experimentation; do not commit or upload.
- EP140 is the pilot.
- Existing episode framework should not be fundamentally replaced.
- The content must avoid information dumping.

Unknowns/open questions:
- What exactly counts as a stage node versus a thought node versus a side-knowledge node?
- Should opened content appear inline, as a side panel, modal, or canvas-like adjacent panel?
- How much text should be visible at each depth?
- Should only one stage/node be open at a time?
- How should "author's idea" differ visually from "AI extension" and "external reference"?

Decision-boundary unknowns:
- Whether to remove existing dense content entirely or keep it as hidden deep nodes.
- Whether the first implementation should be a simple nested accordion or a true interactive map.
- Whether deep node content should be written now for all five stages or only stage one as a prototype.
