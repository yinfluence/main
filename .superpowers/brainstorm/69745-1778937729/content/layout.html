"不乱"的视觉骨架——选一种布局基底

力导向（你现在用的）天生会乱。这是 4 种"先有秩序、再展示丰富"的布局思路。

A. 同心环 / 放射状（radial）

规则：核心放当前焦点（一个概念/模型/人物），按"距离感"分环——核心一层、二级一层、扩展一层。
不乱原因：每个节点都有"固定的环"可去，不会乱飘。
展开方式：点任意节点 → 它成为新核心，整个图重新放射。

B. 分栏列（columns / Sankey-lite）

规则：每种类型一栏——主题 → 模型/概念 → 节目 → 人，左到右垂直对齐。
不乱原因：节点天然按类型站队，连线只能从左到右，几乎不打结。
展开方式：点一栏的项 → 高亮它连到右边的所有项，左侧灰掉无关项。

C. 主题聚类块（cluster zones）

规则：把所有节点按"思想主题"圈进有色块——比如「认知失真区」「权力结构区」「价格/激励区」「信息/媒介区」。区内自由排，区间用虚线连。
不乱原因：区块本身就是分类骨架，先看大格局再看细节。
展开方式：点一个区 → 区放大、其他区收起。

D. 焦点+邻域（focus + halo / progressive disclosure）

规则：任何时刻只清晰显示「焦点节点 + 它的一阶邻居」，二阶以外的节点淡化成灰点。
不乱原因：永远只展示 5-15 个清晰节点，从不超载。
展开方式：点灰点 → 它成为新焦点，原焦点变邻居。像在知识网络里"漫游"。

这一题决定了视觉骨架。可以选一个主，也可以"主+次"（比如 A 主 + D 漫游模式，或 C 看大局 + B 看细节）。
