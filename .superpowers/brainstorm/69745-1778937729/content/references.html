4 个真实参考案例（用 EP001 的真实数据 mockup）

每个 mockup 都对应一种业界做得好的"复杂思想可视化"思路。看看哪一种最贴近你脑子里那个"一条线 + 往外延展"的感觉。

A. 叙事时间轴 + 多线分叉（灵感：XKCD #657）

骨架：横轴是讲者讲述的时间/段落顺序。主线是节目逻辑流（一条粗深蓝线），到了某个论点就分叉出彩色副线（=他展开讲了哪些概念）。
不乱：永远从左到右走，绝不回头。分叉颜色固定对应概念类型。
丰富：每个站点（节点）可点开 → 显示该段的字幕摘录 / viewpoints；副线末端虚线引出 → 跳到其他期相关节点。
对应你说的：✅ 一期=一条线 ✅ 阶段感 ✅ 横向延展（虚线到 EP002/065/071）

B. 思想地铁图（灵感：London Tube / Wardley Map）

骨架：每期一条彩色"地铁线"，每条线穿过若干站点（=论点）。当两期共享同一个概念，那个站点就变成方形换乘站。
不乱：线条只能横平竖直或 45°（octilinear），违反"密度爆炸"。
丰富：换乘站越多 = 这个概念越中心；某条线孤悬不交汇 = 这期是独立思想。
对应你说的：✅ 一期=一条线 ✅ 跨期延展（换乘站） ⚠️ 但少了"时间/阶段感"——地铁站没有先后

C. 思想卷须图（灵感：Quanta Map of Mathematics）

骨架：节目主题居中，3-5 条"卷须"从中心辐射，每条卷须是一个思想方向（品牌咨询/权力结构/价格）。卷须上有几个节点，节点还能长出"子卷须"。
不乱：方向用思想类型分区固定。每条卷须自然形成一个"叙述弧"。
丰富：每个节点点开 = 一段字幕原文 + viewpoint 解读 + 跨期延展。
对应你说的：✅ 丰富 ✅ 可展开 ✅ 用颜色分思想类型 ⚠️ 没有强时间线（卷须不是"先后"而是"分类"）
额外：旁边可以放虚线椭圆显示"他没讲到的"边界外问题。

D. 思想河流图（叙事流 + 支流 + 留白）

骨架：主流（粗深蓝）= 讲者实际讲述的逻辑流，从左到右有方向。支流从主流分叉，往别期延展（不同颜色 = 不同思想类型）。
不乱：主流必横，支流必斜。河流隐喻让"线"和"延展"都很自然。
丰富：每个节点可展开字幕段、viewpoint 解读、相关人物。
对应你说的：✅ 一期=一条主流 ✅ 阶段感 ✅ 横向延展 ✅ 用色 ✅ 留白显示"边界外/未讲到"
额外：灰色半透明云朵 = 讲者没讲到的部分，是你最关心的"遗漏/边界"。

我的初判（如果你想听）：

D（河流图）把你提到的所有需求都收齐了——线、阶段、延展、颜色、边界。A（叙事时间轴）是 D 的简化版，更工整。B（地铁图）跨期全景最强，但单期叙事感弱。C（卷须图）视觉最美但没时间线。
