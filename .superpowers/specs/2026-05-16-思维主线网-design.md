# 单期思维主线网 · Design Spec

**Date**: 2026-05-16
**项目**: 颖响力知识库网页（GoldenVault）
**作者**: ziqiguo + Claude (brainstorming 收敛)
**状态**: 等用户最终复核

---

## 1. 背景与目标

颖响力知识库网页 (`/Users/ziqiguo/Documents/Diary/GoldenVault/md/topic/personal/sources/people/颖响力/网页/`) 当前的单期节目详情页面，展示 viewpoints、concepts、models、人物、跨期关联——但内容堆叠在卡片里，**看不出讲者怎么把问题切分、按什么顺序讲、用了什么核心思维工具、有什么遗漏**。

用户希望在单期页面新增一个**思维主线网**视图：横向呈现讲者讲述的逻辑路线（按段），每段向外辐射延展节点（概念/模型/人物/跨期/边界/批注）。让观众通过这张图**直接看到讲者的思考结构**。

## 2. 核心结构

**「主线（节目的逻辑路线） + 节点上的分支 / 延展 / 补充」**

```
                ●概念    ●模型      ●概念
                |        |           |
段1 ─── 段2 ─── 段3 ─── 段4 ─── ★段5 ─── 段6 ─── 段7 ─── 段8
                |                |    |
               EP002          华与华  EP065
              (跨期)          (人物) (跨期)
```

- **主线** = 讲者实际讲述的 N 段（EP001 是 8 段：开场设问→咨询费→超级符号→帝王思维→**★皇帝的新衣**→商业模式→总结因果→反问收尾）
- **节点上的分支** = 每段关联的概念、模型、人物、跨期节目、边界外问题、用户批注
- **★ 核心段高亮** = 标记 `is_core: true` 的段（讲者把整集论证串起来的关键隐喻段）

## 3. 范围

**In scope**：
- 单期节目页面新增 "思维主线网" 视图区块
- 仅做 EP001 一期作为示范实现
- 数据驱动：依赖 EP001.json 现有字段 + 新增 `segments[]` 字段
- 焦点模式（默认扫读 + 点击爆炸展开）的交互

**Out of scope**（下一迭代）：
- 跨期"宇宙图"视图
- 字幕逐句高亮和原文嵌入
- 移动端深度优化
- NLP 自动分段（先手工在 JSON 里补 `segments[]`）
- 用户批注的协作/持久化

## 4. 数据模型

### 4.1 EP001.json 现有字段（不动）
- `viewpoints[]` `concepts[]` `models[]` `people[]` `relatedEpisodes[]` `topic.boundaries[]`

## 5. 视觉与交互

### 5.1 视觉风格

- **整体方向**：现代极简，参考 Linear / Vercel / Stripe 的克制深色风格
- **背景**：深色 `#0a0a0c` 或 `#0d0d0e`，整页或区块
- **主调**：紫色（节目段节点） + 中性灰文字
- **辅色**：蓝（概念）、绿（模型）、橙（人物）、淡紫（跨期）、虚线灰（边界）
- **核心段**：金色高亮 + 强光晕（仅 1 个 / 期）
- **字体**：sans-serif（系统字体栈，PingFang SC 优先）
- **字号**：节点标签 13-14px、blurb 11-12px、key_quote 14px
- **节点尺寸**：主轴段节点直径 24-30px，分支节点 12-16px
- **连线**：半透明 1px，按类型颜色

### 5.2 交互模式

**默认（扫读模式）**：
- 8 段节点等距排列在主线上
- 每段只显示该段 `branches` 里**最关键的 2 个**（优先级：人物 > 跨期 > 概念 > 模型 > 边界）
- 段 5（is_core）金色高亮 + 光环
- 信息密度低、呼吸感强

**焦点模式（点段节点）**：
- 该段所有 branch 全部展开（爆炸辐射 + fade-in 动画）
- 其他段缩小至 60%、灰化（opacity 0.3）
- 右侧弹出 panel：段标题、blurb、key_quote 字幕引用、按类型分组的所有 branch 列表（可点击）
- 点空白处或 Esc 退出焦点模式

**类型筛选**（图谱顶部）：
- 6 个 toggle：[概念][模型][人物][跨期][边界][批注]
- 关掉某类型 → 该类型分支节点淡出隐藏
- 用于减少信息密度

### 5.3 动画

- 节点 hover：scale 1.15，背景光晕加强，200ms ease
- 焦点切换：300ms fade + scale transition
- 节点出场：分支节点 stagger 50ms 依次出现

## 6. 技术方案

### 6.1 文件改动

| 文件 | 类型 | 改动 |
|---|---|---|
| `content/episodes/EP001.json` | 修改 | 新增 `segments[]` 字段 |
| `src/episode-mainline.js` | 新建 | 主线网渲染组件（SVG + DOM） |
| `src/style.css` (或 assets/style.css) | 修改 | 新增 `.mainline-*` 样式块 |
| `src/app.js` 或 episode 渲染逻辑 | 修改 | 在 EP001 详情页挂载 mainline 组件 |
| `build.mjs` | 视需要 | 确保新 JS 文件被打包 |

### 6.2 实现要点

- 用纯 SVG + 少量 DOM，不引入新依赖
- 段节点坐标：均匀分布 x = (width - 2*pad) / (N-1) * i + pad, y = height / 2
- 分支节点坐标：极坐标布局，上半圆放概念/模型，下半圆放人物/跨期/边界
- 焦点模式：增加 `.focused` class 到容器，CSS transition 处理灰化与缩放
- panel：右侧 fixed 抽屉，width 360px，从右滑入

### 6.3 渐进式实现顺序

1. EP001.json 加 segments[]（手工提炼 8 段）
2. episode-mainline.js 静态渲染主线 + 段节点（不带分支）
3. 加分支节点（扫读模式：每段 2 个）
4. 加焦点模式 + panel
5. 加类型 filter
6. 加动画

每步都能 build + 在浏览器看到。

## 7. 验收标准

- ✅ EP001 详情页能看到横向思维主线网
- ✅ 视觉上比现有实现"克制、现代、不像 demo"
- ✅ 默认扫读状态干净，不超载
- ✅ 点段节点能切到焦点模式，能看到 key_quote 字幕引用
- ✅ 段 5 ★ 金色高亮显眼
- ✅ 不破坏 EP001 详情页其他区块、不影响其他 episode

## 8. 风险与未决

- 现有 episode 详情页 layout 不确定是否容纳全宽主线网 — 实施时确认
- `segments[]` 手工补充 8 段是临时方案，扩展到 140 期需要 NLP 流水线（下个迭代）
- 焦点模式下某些段的 branch 仍可能过多（如段 5 有 10+ 个）—— 用 filter 缓解，必要时分组折叠

## 9. 后续路线（不在本次范围）

- **跨期宇宙图**：每期是这样一条"路线"，多条路线通过共享概念/人物互联，形成 140 期的全景图
- **字幕逐句高亮**：把 raw .md 字幕嵌进每段，关键句行内高亮
- **批注协作**：用户可以在节点上加 annotation 并云端持久化
- **自动 segment 提炼**：基于字幕 + viewpoints 用 LLM 自动生成 segments[]
